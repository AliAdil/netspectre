1. EXECUTIVE OVERVIEW & CAPABILITIES

NETSPECTRE bridges the gap between low-level packet sniffers (like Wireshark) and per-application firewalls (like GlassWire). Traditional tools present overwhelming raw hex dumps or oversimplified numbers. NETSPECTRE combines deep Windows kernel-level socket awareness with a futuristic 2.5D neural visualization command center.

Primary Business & Security Questions Answered

Question What NETSPECTRE Discloses
What data enters my PC? Real-time download throughput (B/s, KB/s, MB/s), cumulative downloaded volume, and individual inbound frame packet sizes.
What data leaves my PC? Real-time upload speed, cumulative sent bytes, and outbound request frame sizes with directional tracking.
Which application is talking? Exact process name (chrome.exe, Unity.exe, msedge.exe, svchost.exe), Process ID (PID), and physical binary path on disk.
Where is it sending data? Observed remote IPv4/IPv6 addresses, resolved domain names (FQDN), and remote destination ports (443, 53, 80, 8080).
Who owns the remote server? Hosting organization attribution (Cloudflare, Microsoft Azure, Google Cloud, AWS), Autonomous System Number (ASN), and country geolocation flags.
Which protocol is used? Transport protocol (TCP / UDP) and application classification (TLS 1.3 / HTTPS, QUIC / HTTP3, DNS 53, mDNS 5353).
Is the data encrypted? Full cryptographic transparency: clearly labels encrypted payloads (TLS 1.3/QUIC) vs unencrypted traffic without deceptive claims.

3. QUICK START & LAUNCH INSTRUCTIONS

3.1 System Prerequisites

  • Operating System: Windows 10 or Windows 11 (64-bit edition).
  • Runtime: Microsoft .NET Framework 4.5 or higher (pre-installed on all modern Windows systems).
  • Node.js: Node.js v18+ with npm (for desktop frontend rendering).

3.2 One-Click Desktop Launch

To start the application, navigate to the application root directory and double-click the launcher:

launch.bat

The launcher performs the following automated verification sequence:

  1. Checks if src-engine\NetSpectreEngine.exe exists; if missing, automatically compiles it using the native 64-bit C# compiler.
  2. Verifies that the telemetry service is responding on http://127.0.0.1:48123/api/status.
  3. Spawns the Electron desktop command center with hardware acceleration enabled.

3.3 Command-Line Startup Options

Command Purpose
launch.bat Primary one-click user launcher for the complete suite.
npm.cmd run electron Launches the desktop Electron GUI in production mode.
npm.cmd run build:ui Recompiles Vite, TypeScript, Tailwind CSS, and WebGL assets.
.\src-engine\NetSpectreEngine.exe --port 48123 Runs the native C# telemetry daemon as a standalone console service.

7.2 Cryptographic Transparency Notice

TRANSPORT ENCRYPTION (TLS 1.3 / QUIC) REALITY
Modern HTTPS and QUIC traffic is encrypted end-to-end between the client and remote endpoint using Ephemeral Diffie-Hellman keys (ECDHE). NETSPECTRE adheres strictly to genuine technical accuracy: it truthfully captures packet sizes, arrival intervals, and endpoint addresses without deceptively claiming to read encrypted passwords or private tokens on the wire.

7.3 Mode B: Optional Browser Request Observability

For browser sessions (such as ChatGPT, Google, or YouTube), switch the top toggle to Mode B: Browser Observability.

  • Click ENABLE USER CONSENT to authorize request-level observability.
  • Displays higher-level HTTP request URLs (e.g. POST https://chatgpt.com/backend-api/conversation), HTTP status codes (200 OK), content types (application/json), and transfer sizes.

8. WIRESHARK INTEGRATION & PCAP EXPORT

NETSPECTRE includes an integrated packet capture generator for deep forensic analysis:

  1. Click the PCAP button in the top navigation bar.
  2. NETSPECTRE exports a standard binary PCAP file (magic number 0xa1b2c3d4) containing captured Ethernet and IP frames.
  3. Double-click the exported .pcap file to open it directly in Wireshark.
DEVELOPER TIP: TLS PAYLOAD DECRYPTION IN WIRESHARK
If you wish to view decrypted HTTP payloads in Wireshark for your own browser sessions: set the Windows environment variable SSLKEYLOGFILE=C:\sslkeys.log, restart your browser, and point Wireshark's TLS preferences (Edit → Preferences → Protocols → TLS → (Pre)-Master-Secret log filename) to that file.

10. TROUBLESHOOTING & FREQUENTLY ASKED QUESTIONS

Q1: Why does PowerShell show a SecurityError regarding npm.ps1?

Windows PowerShell disables .ps1 script execution by default. Always launch the application using launch.bat or call npm.cmd directly instead of npm.

Q2: Can NETSPECTRE decrypt HTTPS passwords or banking details?

No. In accordance with zero-trust security and technical honesty, NETSPECTRE never compromises cryptographic security. It monitors network dynamics, socket metadata, and packet timings without intercepting private credentials.

Q3: How do I change the engine port if 48123 is occupied?

Launch the engine with the custom port flag: NetSpectreEngine.exe --port 50123, and update the port in NETSPECTRE Settings or store configuration.
